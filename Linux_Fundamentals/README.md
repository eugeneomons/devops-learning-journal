# Linux Fundamentals

This folder contains my notes, practice exercises, and mini‑projects from learning Linux.  
Most of my hands‑on experience comes from KodeKloud labs and playground environments, where I practiced real server administration tasks.

Linux is the foundation of DevOps, and this section documents the core skills I’ve built since January 2026.

---

## 📘 Topics Covered

- Basic navigation (ls, cd, pwd)
- File and directory management (cp, mv, rm, mkdir)
- Viewing and editing files (cat, less, nano, vi)
- Permissions and ownership (chmod, chown)
- Processes and system monitoring (ps, top, kill)
- Package management (apt, yum)
- System services (systemctl)
- Networking basics (ping, curl, netstat, ss)
- Environment variables and shell configuration
- SSH and remote server access
